# Lab and Equipment Booking System

A MERN stack application for managing laboratory resources and equipment bookings.

## Live Demo
https://lab-equipment-booking-nu.vercel.app

## GitHub Repository
https://github.com/thanvi-12/lab-booking-system

## Technologies Used
- MongoDB
- Express.js
- React.js
- Node.js
- JWT Authentication

## Features
- Student and Admin login
- Resource management
- Equipment booking
- Booking management
- Role-based access control
